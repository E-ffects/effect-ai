# PCB RMA v4 데이터 사전

`sample_csv/`의 파일 55개(테이블 45 + 뷰 10)가 무엇이고, 각 컬럼이 무슨 뜻인지 정리한 문서다.

## 읽기 전에
- **sample_csv는 미리보기다.** 각 파일은 해당 테이블의 **앞 100행**만 담고 있다. 전체 데이터는 `pcb_rma.sqlite`에 있다. 100행 이하인 테이블(기준 정보 등)은 CSV가 전체와 같다.
- **파일 이름 = 테이블 이름.** `rma_claim.csv`는 DB의 `rma_claim` 테이블이다.
- **시각 형식:** `2025-01-06T08:30:46+09:00` (한국 시간, ISO 8601)
- **`_json`으로 끝나는 컬럼:** 값이 JSON 문자열이다. 예: `["EVID-0000001", "EVID-0000002"]`
- **0/1 컬럼:** 1 = 예, 0 = 아니오
- **ID 접두어:** `RMA-` 반품 접수, `ITEM-` 반품 품목, `LT-` 생산 Lot, `RUN-` 공정 실행, `TEST-` 검사, `INV-` 조사, `CAUSE-` 원인 판정 등
- 건수는 v4 전체 DB 기준이다.

## 테이블 연결 한눈에 보기
```
[접수] rma_claim ─ rma_item ─ symptom_assessment (소분류)
                │        └ qa_triage (심각도·분석 수준)
                │
[추적]          └ rma_item.lot_id → production_lot → process_run → process_observation (공정 조건)
                                       │               └ equipment_master / equipment_event (설비)
                                       ├ material_usage → material_lot → supplier (자재)
                                       ├ test_run → test_measurement (검사)
                                       └ shipment_lot → shipment (출하)
[원인]  investigation ─ investigation_claim (반품 연결)
          ├ cause_assessment (원인·공정·장비) ─ claim_cause (반품별 적용)
          ├ escape_assessment (유출 원인)
          └ corrective_action → effectiveness_check / recurrence_review (조치·효과·재발)
```

COPQ(품질 실패 비용) 틀로 계산한 **가정 단가 기반 추정 손실**이다. 설계와 결과는 `PCB_RMA_v4_수정내역.md`를 본다.

### `cost_rule.csv`: 가정 단가표 (66행)
모든 단가·배수·상한이 여기 한 곳에 있다. 값을 바꾸고 `patch_v4_loss.py`부터 다시 실행하면 전체가 다시 계산된다.
| 컬럼 | 의미 | 값 예시 |
|---|---|---|
| rule_id | 규칙 ID | PANEL_COST_PER_LAYER, STAGE_FIELD, CAP_AUTOMOTIVE, LAB_XSEC_CRACK |
| rule_group | 묶음 | BOARD(기판 원가), CHARGEBACK(고객 측 손실), HANDLING(물류·선별·공수), CONTAINMENT(봉쇄), LAB(시험) |
| value | 값 | 8000 |
| unit | 단위 | KRW/panel/layer, x board price, KRW/claim |
| basis | 근거·설명 | 표준 FR-4 다층 패널의 층당 자재·공정 변동비 가정 |
| is_assumption | 가정값 여부 | 1 (전부 가정) |

### `product_cost.csv`: 제품별 원가 (6행)
| 컬럼 | 의미 | 값 예시 |
|---|---|---|
| spec_id | 제품 | AUTO-RADAR8 |
| panel_cost_krw | 패널 원가 | 143120 |
| board_cost_krw | 기판 원가 (패널 원가 ÷ 패널당 기판 수 ÷ 수율) | 9416 |
| board_price_krw | 기판 판매가 (원가 × (1 + 마진)) | 12241 |
| basis | 계산식 | 패널 = 8,000 x 8층 x 2.08(HDI, 저손실 자재) + ENIG 10,000; … |

### `loss_ledger.csv`: 손실 원장 (56,067행)
비용이 생긴 사건 하나가 한 행이다. **대시보드의 손실 금액은 이 테이블에서 계산한다.**
| 컬럼 | 의미 | 값 예시 |
|---|---|---|
| ledger_id | ID | LOSS-0000001 |
| cost_category | COPQ 분류 | EXTERNAL_FAILURE(외부 실패), APPRAISAL(분석·평가), CONTAINMENT(봉쇄) |
| cost_type | 비용 항목 | REPLACEMENT_BOARDS, CREDIT_REFUND(환불), CUSTOMER_CHARGEBACK(고객 측 손실 청구), SORTING_SUPPORT, LOGISTICS, LAB_ANALYSIS, ENGINEERING, CONTAINMENT_SORT, CONTAINMENT_REWORK, CONTAINMENT_SCRAP, CONTAINMENT_RETURN_REPLACE |
| rma_id / rma_item_id | 관련 반품 (봉쇄 비용은 비어 있음) | RMA-05616 |
| investigation_id | 관련 조사(패턴) | INV-25-0013 |
| customer_id | 고객 | A10 |
| spec_id | 제품 | AUTO-RADAR8 |
| quantity / unit | 수량 / 단위 | 119 / board |
| unit_cost_krw | 단가 | 122405 |
| amount_krw | 금액 | 14566226 |
| basis | 계산 근거 | 불량 119장 x 판매가 x 발견 단계 배수 10 (ICT_FUNCTION) |
| source_table / source_id | 비용을 만든 원천 레코드 | service_action / SVC-0000001, claim_cause, test_run, return_receipt, containment_action |
| occurred_at | **비용 발생 시각** (기간 합계와 시점 통제의 기준) | 2025-09-15T20:26:40+09:00 |

`return_receipt`, `containment_action`은 v4 DB에서 정리된 테이블이라 `source_id`는 값으로만 남아 있다.
