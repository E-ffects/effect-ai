# PCB RMA v31 · 데이터 감사 및 수정 내역

## 메일 반영 평가

v30은 v29의 SSD 데이터를 일부 바꾼 판이 아니라, PCB 원판을 대상으로 다시 만든 합성 데이터다. SK AX 회신은 유사 사업을 바탕으로 한 프로젝트 요구사항으로 해석했다. QA가 접수 직후 위험과 영향 범위를 검토하고, 공정·자재·검사 기록으로 발생과 유출 원인을 구분하며, 영향 LOT와 후속 조치로 이어지는 설계가 회신 방향에 맞는다. 제조 포장 실링은 공장 관리 공정이며 운송 중 과실과 구분된다.

## 접수 증상과 QA 시험 비교

DBeaver에서 `qa_symptom_reproduction`을 열면 원문 분류 코드, 회수 시험 ID, 출처 검증 여부, 재현 상태와 최종 원인 후보를 한 행에서 볼 수 있다. 원문은 `rma_claim`, 개별 측정은 `test_measurement`에서 연결한다. 전용 시험 항목에 직접 매핑되는 증상만 자동으로 비교한다. 리플로 블리스터는 받은 상태의 시료 조건을 비교하며 베이킹 후 측정은 별도로 볼 수 있다.

| 판정 | 건수 | 해석 |
|---|---:|---|
| REPRODUCED | 5,201 | 출처가 확인된 반송품에서 해당 증상에 대응하는 시험 항목이 규격 이탈 |
| NOT_REPRODUCED | 522 | 출처가 확인된 반송품에서 해당 시험 항목이 기록된 조건에서 규격 이내 |
| REVIEW_REQUIRED | 3,069 | 범용 시험, 매핑 없음, 증상 조건을 추가로 검토할 필요 등 |
| UNVERIFIED_SAMPLE | 642 | 시험은 있으나 반송품 출처 검증 필요 |
| NOT_TESTED | 566 | 기준 시점까지 완료된 반송품 시험 없음 |

- P02 `RMA-01290` → `TEST-00360929` → 리플로 블리스터 재현 → PRS-02 적층 미경화.
- P18 `RMA-03388` → `TEST-00362977` → 리플로 블리스터 재현 → PCK-02 제조 포장 실링 문제로 흡습.

## 평가 해석

조사 계열 분할은 학습 6,983건, 검증 1,509건, 테스트 1,508건이다. 클래스 커버리지는 분할마다 다르다. 시간 분할은 시점 검증에, 조사 분할은 같은 사건을 학습하고 다시 맞히는 효과를 줄이는 데 사용한다. 원인은 생성 규칙으로 만들었고 시험 항목 선택에도 생성상 원인 정보가 관여한다. 실제 원인 추론 성능은 접수/QA 시점별 입력을 고정하고, 사람이 작성한 독립 사례와 근거로 별도 검증해야 한다.

테이블은 55개, 뷰는 14개, 접수는 10,000건이다. SQLite 무결성·외래 키와 시나리오별 검사 결과는 `manifest.json`에 있다.
