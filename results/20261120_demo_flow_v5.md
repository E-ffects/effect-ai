# 시연 흐름 점검 (2026-11-20, v5, LLM gpt-5.4-mini, 학습 재정렬 꺼짐)

`server/app.py`를 띄우고 `scripts/demo_flow.py`로 Spring과 같은 순서(분류 → 판정 → 분석 등록·폴링 → 유사 사례)로 샘플 6건을 불렀다. 시연 전에 같은 명령으로 다시 확인하면 된다.

## 요약
- **6건 모두 정상.** 분류 1.2~1.9초(Spring 제한 10초), 판정 0.02초, 분석 등록 0.01초, 분석 완료 8~10초(Spring 대기 40초), 유사 사례 0.03초.
- 임시 판정(RMA-07936, 정보 부족)은 분석 없이 멈추고 재질의 문구가 나온다(Spring_API_v4 4-6).

## 시연 때 주의
- **"외관 NG"만 적힌 접수(RMA-07936)는 LLM 분류가 갈린다.** 같은 원문 6번 중 4번 정보 부족, 2번 APPR03(온도 0이어도 OpenAI 응답이 완전히 고정되지 않음). 재질의 장면을 보여 줄 때는 결과를 미리 확인하거나 Spring 목업 응답을 쓴다. 분류 규칙을 바꾸려면 분류 평가를 다시 돌려야 해서 이번에는 바꾸지 않았다.
- `LLM_OUTPUT_REJECTED`가 가끔 붙는다(근거에 없는 숫자를 LLM이 써서 그 문장만 템플릿으로 바꿈). 상태는 `SUCCEEDED`이고 순위·근거는 같다.
- 고객 회신은 원인이 단발성(취급 스크래치, L1)이어도 "동일 Lot 재고 출하 보류"를 쓴다. 팀 정책에 맞는지 확인이 필요하다.
